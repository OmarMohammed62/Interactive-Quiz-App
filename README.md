Interactive Quiz App

An interactive quiz application built using HTML, CSS, and JavaScript.

Live Demo

"Try the Quiz App" (https://omarmohammed62.github.io/Interactive-Quiz-App/)

Features

- Multiple-choice questions.
- Instant feedback for correct and incorrect answers.
- Previous and Next question navigation.
- Save and restore selected answers.
- Change answers before completing the quiz.
- Automatic score calculation.
- Restart the quiz functionality.
- Responsive design for different screen sizes.

Technologies Used

- HTML5
- CSS3
- JavaScript
